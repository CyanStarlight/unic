# Sets

## Definition
- A set is a collection of objects called __elements__ of the set.
- The elements of a set can be anything: numbers, letters, symbols, etc.
- The elements of a set are __distinct__, and the order of the elements does not matter.

## __Notation:__ Sets are denoted by a capital letter, and the elements of the set are enclosed in curly braces.
   If $A$ is a set, then $A = \{2, 4, 7, 11, \ldots\}$.
    - __Example:__ The set of all vowels in the English alphabet is denoted by $V = \{a, e, i, o, u\}$.
   A set is called __finite__ if it has a finite number of elements, and __infinite__ otherwise.
    - __Examples:__ The set of all natural numbers is an infinite set.
      - $\mathbb{B} = \{324, 34, 2, 49, 5\}$.
      - $\mathbb{N} = \{1, 2, 3, 4, \ldots\}$.

   If $x$ is an element of a set $A$, we write $x \in A$.
    - __Example:__ If $A = \{1, 2, 3, 4, 5\}$, then $3 \in A$.
      - If $x$ is not an element of a set $A$, we write $x \notin A$.
    - __Example:__ If $A = \{1, 2, 3, 4, 5\}$, then $6 \notin A$.

   We can __describe a set__ using one of the following methods:
     A ___listing___ or ___enumeration___ method: We list all the elements of the set.
      - __Example:__ $A = \{1, 2, 3, 4, 5\}$.
     ___Predicate___ or ___set-builder___ method: We describe the set using a property that its elements satisfy.
      - __Example:__ $A = \{x : x \text{ is a natural number and } 1 \leq x \leq 5\}$.

 __Commonly used sets___:
    - $\mathbb{U}$: The __universal set__ is the set that contains all the elements under consideration.
    - $\emptyset$: The __empty set__ is the set that contains no elements.
    - $\mathbb{N}$: The set of all natural numbers.
    - $\mathbb{N_0}$: The set of all non-negative integers.
    - $\mathbb{Z}$: The set of all integers.
    - $\mathbb{Q}$: The set of all rational numbers.
    - $\mathbb{R}$: The set of all real numbers.
  
  ## __Subsets__
  - A set $B$ is a ___subset___ of $A$ if every element of $B$ is an element of $A$
  - This is denoted by $B \subseteq A$.
    - __Example:__ If $A = \{1, 2, 3, 4, 5\}$ and $B = \{2, 4\}$, then $B \subseteq A$.

    ### Equality of Sets
    - Two sets are equal if they have the same elements.
    - This is denoted by $A = B$.
      - __Example:__ If $A = \{1, 2, 3, 4, 5\}$ and $B = \{5, 4, 3, 2, 1\}$, then $A = B$.ox
