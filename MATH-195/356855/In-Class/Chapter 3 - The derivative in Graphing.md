### Analysis of functions $\mathbb{I}$: Increase/Decrease & Concavity
For Increase / Decrease:
- $mx+c$
- where $m$ is the gradient
	- if $m>0$: function is increasing, else otherwise
- $c$ is the y-intercept

A function $f(x)$ is:
- **increasing** on an interval if $f'(x)>0$ on that interval
- **decreasing** on an interval if $f'(x)<0$ on that interval

> e.g. $f(x) = x^2$ . Find where ($x$-intervals) the $f(x)$ is increasing/decreasing
> We need $f'(x) = 2x$
> $\rightarrow$ We solve $2x=0$
	 $\rightarrow$ $x=0$
> $f'(x) = x^2$
> **decreases** in $(-\infty<x<0)$
> **increases** in $(0<x<\infty)$

>e.g $f(x)=x^3$
>$f'(x)=3x^2$
>Solve $f'(x)=0 \rightarrow x=0$ 

#### Concavity:
a Function $f(x)$ is:
- Concave **up** is $f''(x)>0$ 
- Concave **down** is $f''(x)<0$

#### A point of inflections
is on $(x,y)$ where $f''(x)$ changes sign (concavity changes)

Graphical representation of points of inflection
- Concave up $\cup$ shape
- Concave down $\cap$ shape
