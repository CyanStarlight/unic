## Exercise 3: Code Collaboration

- Used GitHub repository for code sharing
- Created repo, pushed initial code with main() and one function
- Added collaborator to access the repository

### b) Code Combination Process
- Other student implemented two functions and pushed changes
- I pulled their changes and implemented the final function
- Resolved any conflicts and tested the combined program

### c) Self-Implementation
- Created two working directories to simulate multiple developers
- Implemented different functions in each environment
